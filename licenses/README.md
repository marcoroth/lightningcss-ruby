# Licenses of what this gem builds against

A precompiled gem ships a native extension with [Lightning CSS](https://github.com/parcel-bundler/lightningcss) compiled into it, so the terms that cover Lightning CSS cover part of what is being distributed.

The license is carried here so that whoever received the gem has the terms in hand.
